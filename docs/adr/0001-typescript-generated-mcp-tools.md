# Use TypeScript and generated MCP tools

This project uses Node.js 22+, TypeScript, `@modelcontextprotocol/sdk`, `zod`, built-in `fetch`, and `vitest`. MCP tools are generated from all operations in `docs/mekari.swagger.json` rather than handwritten or allowlisted, because Mekari Jurnal exposes many API operations and this project is an API-to-MCP translation layer where traceability to Swagger matters more than custom business workflows. Generated modules live under `src/generated/`, while reusable config, auth, and HTTP client code stay outside that directory so generated code can be replaced safely. The generator preserves Swagger tag boundaries, normalizes names for MCP, and repairs malformed Swagger paths that include query strings by splitting query parameters into tool inputs. Read operations are registered by default, mutation operations require `MEKARI_ENABLE_MUTATIONS=true`, destructive operations also require `MEKARI_ENABLE_DESTRUCTIVE=true`, and `MEKARI_MODULES` can narrow registered modules at runtime; disabled operations are hidden from the MCP registry to keep AI client tool lists clean. The initial MCP transport is stdio only, because the first use case is local AI clients and HTTP transport would add remote exposure and server auth concerns before they are needed.
